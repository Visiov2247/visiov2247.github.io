Once you install the software, open it from your desktop icon. The application opens a local window. You see several tabs at the top. Each tab shows different performance areas. You can filter data by date or specific project files. The charts update in real time while you work in your Autodesk software.

💡 Frequently asked questions

Does this tool send my data to the internet? No. All processing happens on your local device.

Will this slow down my system? The dashboard uses minimal resources. It is designed for lightweight monitoring.

Can I export the reports? Yes. Each view includes an export button to save data as a spreadsheet file.

🔧 Troubleshooting

If the dashboard fails to load, verify that your Autodesk software is open. Ensure that your firewall permits the application to read local system logs. Restart the application if you notice the charts stop updating.
